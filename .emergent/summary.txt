**original_problem_statement:**
The user wants to develop a full-stack, cross-platform (Android/iOS) mobile application for a football pool, built with a professional architecture. The application will feature two main modes: Quiniela Tradicional (Traditional Pool) and Fantasy Fútbol.

**PRODUCT REQUIREMENTS:**
-   **User System:** Secure user registration (email/password), login, password recovery, and a user profile displaying name, photo, and statistics.
-   **Main Menu:** A simple home screen with two large buttons to navigate to Quiniela Tradicional or Fantasy Fútbol.
-   **Quiniela Tradicional Mode:**
    -   Display weekly matches of the Mexican league.
    -   Users can predict the outcome (Win A, Draw, Win B) for each match.
    -   Selections must be submitted before the first match of the round begins.
    -   User selections are saved in a database.
    -   At the end of the week, the system calculates points for correct predictions and updates user scores and a general leaderboard.
-   **Fantasy Fútbol Mode:**
    -   Users create and manage their own fantasy team with a 4-4-2 formation (1 GK, 4 DF, 4 MF, 2 FW) plus a Head Coach (DT).
    -   An interactive, visual representation of a football pitch is used for lineup management.
    -   Users select players for each position by first choosing a real team from the league, then a player from that team's roster.
    -   The visual pitch updates to show the selected player's jersey and number.
    -   An automatic scoring system awards points based on real-world player performance (goals, assists, clean sheets, etc.).
    -   Team lineups are locked once the round (jornada) starts.
-   **Private Leagues:**
    -   Users can create private leagues and invite friends using a unique shareable code.
    -   A dedicated screen will display a results matrix after each round, showing each participant's prediction (correct/incorrect) for every match.
    -   Leagues will have their own leaderboards (weekly and general).
-   **Technical & Design:**
    -   Start with mocked data, with the ability to integrate a real-time sports data API later.
    -   Integrate a payment system (PayPal preferred).
    -   Implement push notifications for key events (e.g., match start reminders).
    -   The UI should have a minimalist, sporty design with a color palette of black, red, and strong blue.
    -   The app's language must be Spanish.
